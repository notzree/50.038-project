Overnight Formula Experiment Run Order

Goal
- Evaluate multiple human-feature formula sets and pick the best by validation/CV metrics.

Run order (recommended)
1) Set A (baseline)
2) Set E (balanced)
3) Set B (rhythm-heavy)
4) Set C (timbre-heavy)
5) Set D (acoustic-contrast)
6) Set F (nonlinear-lite)

Why this order
- Start with a baseline and a stable balanced alternative.
- Then explore directional biases (rhythm/timbre/acoustic).
- Finish with nonlinear variant for possible lift.

Selection criteria
- Primary: validation F1
- Secondary: validation ROC-AUC and calibration quality
- Tie-breaker: better positive-class recall at acceptable precision

Protocol guardrails
- Do not use test set for formula selection.
- Keep train/val split and random seed fixed during formula comparisons.
- Save every run config and metric artifact for reproducibility.

Artifacts to log per run
- formula_set_id
- exact coefficients/formula
- validation metrics (F1, precision, recall, ROC-AUC)
- selected threshold and confusion matrix
- timestamp and git commit hash
