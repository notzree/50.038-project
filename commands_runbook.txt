Project command runbook

1) Install dependencies
uv sync

2) Run full pipeline with existing songs
uv run python src/run_pipeline.py

3) Run full pipeline with fresh viral download
uv run python src/run_pipeline.py --download --limit 100

4) Run full pipeline with additional non-viral download
uv run python src/run_pipeline.py --download-nonviral --nonviral-limit 300 --nonviral-popularity-threshold 25

5) Extract full audio features manually
uv run python src/extract_features.py --manifest src/data/audio_manifest.csv --output src/data/audio_features.csv --feature-set full

6) Build high-level proxy features
uv run python src/engineer_high_level_features.py --input src/data/audio_features.csv --output src/data/audio_features_high_level.csv

7) Run dataset QC
uv run python src/qc_audio_dataset.py --manifest src/data/audio_manifest.csv --features src/data/audio_features.csv

8) Build labels + train table
uv run python src/build_dataset.py

9) Train model and save artifacts
uv run python src/train_model.py --input src/data/train_table.csv --metrics-out src/data/model_metrics.json --model-out src/data/model.joblib --region-metrics-out src/data/region_metrics.csv

10) Generate visualization set
uv run python src/make_visualizations.py --out-dir src/data/plots

11) Run formula-set search experiment
uv run python src/optimize_high_level_formulas.py --formula-sets A,B,C,D --seeds 42 --output-dir src/data/formula_search

12) Promote selected formula run and apply country profile (example: set A, seed 42)
uv run python src/promote_formula_run.py --set A --seed 42 --apply-country-profile

13) Preview the Streamlit UI
uv run streamlit run src/app/user_interface.py

Notes
- Pipeline is CSV-first.
- Manifest path: src/data/audio_manifest.csv
- Track catalog path: src/data/track_catalog.csv
- Features path: src/data/audio_features.csv
- High-level features path: src/data/audio_features_high_level.csv
- Country profile path: src/data/country_profile_features.csv
- Songs directory: src/data/songs/
