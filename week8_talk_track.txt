Week 8 talk track (2-3 minutes)

Problem framing
- We predict whether a song will appear in a given region's Spotify top200 chart.
- Unit of prediction is (track_id, region).

Data and preprocessing
- We use spotify-charts data for historical chart presence by region.
- We download short audio clips and extract basic acoustic features.
- We generate a binary label appears_in_region: 1 if song appears at least once in that region's top200, else 0.

Modeling approach
- We start with a simple, explainable baseline (logistic regression).
- We compare against random forest as a stronger non-linear model.
- Because labels are imbalanced, we focus on F1/ROC-AUC, not only accuracy.

Results snapshot
- Data is highly imbalanced (about 2.5% positives in current subset).
- Random forest currently outperforms logistic regression on F1 and ROC-AUC.
- We also produce per-region metrics and error tables to inspect false positives/false negatives.

Live demo flow
1) Run end-to-end pipeline command.
2) Show metrics JSON and selected model.
3) Run single-audio inference with region input.

Limitations and next steps
- Current model is MVP-level due to small subset and limited feature scope.
- Next, we will scale data, add richer features/context, and move toward time-window virality targets.
